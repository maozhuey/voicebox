## Purpose

确保声音档案卡片在用户选择声音或切换生成引擎时维持稳定的位置，避免无关的列表重排干扰用户继续操作。

## ADDED Requirements

### Requirement: 声音档案卡片顺序稳定
系统 SHALL 按声音档案接口返回的顺序展示卡片。在声音档案集合未发生新增、删除或刷新替换时，用户点击任意卡片、取消选择卡片或由选择行为引起生成引擎变化，均 MUST 不改变所有已展示卡片之间的相对顺序。

#### Scenario: 点击非首张卡片后保持顺序
- **WHEN** 列表按接口返回顺序展示至少三张声音档案卡片，用户点击其中一张非首张卡片
- **THEN** 该卡片的选中态按既有规则更新，且卡片 DOM/视觉顺序与点击前完全一致

#### Scenario: 点击卡片引起生成引擎变化后保持顺序
- **WHEN** 用户选择一张卡片导致当前生成引擎变为另一种引擎
- **THEN** 新引擎不支持的卡片仍按原位置显示为禁用态，所有卡片的相对顺序保持不变

#### Scenario: 再次点击取消选择后保持顺序
- **WHEN** 用户点击当前已选中的卡片以取消选择
- **THEN** 选中态被清除，且卡片顺序与取消前完全一致

#### Scenario: 档案集合变化时按最新数据顺序展示
- **WHEN** 声音档案集合因创建、删除或查询刷新而替换为新的接口返回结果
- **THEN** 系统按最新结果本身的返回顺序展示卡片；此规则不要求保留已不存在档案的位置
