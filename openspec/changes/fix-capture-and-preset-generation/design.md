## Context

见 [proposal.md](proposal.md) 的动机。目前声音档案兼容性规则由前端选择器和后端 `validate_profile_engine` 分别维护；前端虽然会在档案切换后通过 effect 调整模型，但 effect 在渲染后执行，提交事件可在该同步前读取到上一档案的引擎。捕获路由会把未分类异常统一转换为 500，而客户端只将无法识别的服务端 detail 降级为状态码文案；服务端标准错误输出由桌面 sidecar 的管道消费，失败后无法查询。

## Goals / Non-Goals

**Goals:**

- 以同一份纯函数兼容性规则驱动模型选项、档案切换和提交前校验，保持“切模型不改声音、切预设声音才改模型”的用户意图。
- 将听写错误分为可恢复的录音输入错误与内部转写错误；内部错误可通过不含敏感内容的诊断编号回查。
- 覆盖用户报告的两种回归路径，并继续保留后端的最终兼容性保护和成功录音流程。

**Non-Goals:**

- 不改变预设声音与克隆声音的引擎能力矩阵，不让 CustomVoice 支持克隆录音。
- 不更改模型下载策略、Whisper 推理算法、已有捕获/生成数据或云端 API。
- 不将原始音频、转写文本、完整文件路径或 Python 堆栈写进用户可见文案或诊断条目。

## Decisions

### 1. 以声音档案为兼容性约束的唯一来源

在前端抽出“档案 + 引擎 → 兼容性/恢复建议”的纯函数，并在选择器、档案切换和提交处复用。预设档案的恢复建议是其 `preset_engine`；克隆档案遇到仅预设引擎时没有自动恢复到其他声音的建议，因此保留档案并阻止该模型选择。提交处理在调用 API 前以当前已加载的档案再次验证，消除 React effect 尚未落地的时间窗口。

备选方案是仅依赖服务端 400。它不需要前端代码，但用户仍会在点击后失败，且不能解决陈旧表单状态；因此不采用。另一方案是在用户选择 CustomVoice 时自动改选第一个预设声音，会改变用户声音意图，明确不采用。

### 2. 后端继续保留确定性的最终防线

后端仍在创建生成记录之前验证档案/引擎组合并返回 400。客户端展示的中文兼容性说明由同一规则映射产生，但不替代服务端，以保护 MCP、旧客户端和直接 API 调用。

### 3. 捕获失败采用阶段化的本地 JSONL 诊断

捕获创建为每个请求分配短诊断编号。录音读取/解码失败属于用户可恢复输入错误：返回 400 且不记录为内部故障。模型加载、转写与其他未预期异常会写入应用数据目录下的仅追加 JSONL 诊断条目，再返回带诊断编号的安全 detail。条目只包含编号、UTC 时间、阶段（`model_load`、`transcribe` 或 `internal`）、来源、文件扩展名、模型大小、异常类型和截断后的异常摘要；不保存音频、转写正文、绝对路径或堆栈。

JSONL 不需要数据库迁移，进程崩溃后仍可保留此前失败；单条写入失败不得掩盖原始请求失败。备选方案是在 SQLite 建表，查询更方便但增加迁移、保留策略和损坏恢复面；本次仅需要本地排障，采用 JSONL 的最小实现。

### 4. 客户端只识别受控的错误协议

客户端错误格式化器识别预设声音兼容性与捕获诊断编号，显示中文行动建议和编号；未知 500 仍使用安全的通用提示。复制错误将复制同一安全文本，不回传或展示服务端堆栈。解码错误沿用“录音损坏或格式不受支持”的用户文案。

## Risks / Trade-offs

- [前端规则与后端规则今后再次漂移] → 为两端增加相同场景的回归测试，后端始终拒绝不兼容组合。
- [诊断摘要可能意外包含敏感文件信息] → 只记录异常类型和受控截断摘要，写入前清理绝对路径、音频内容及转写正文。
- [JSONL 写入失败或日志无限增长] → 诊断写入采取 best-effort 并设定单文件大小/轮转上限；错误响应不依赖日志写入成功。
- [合法 WebM 被解码器暂时拒绝] → 继续采用既有规范化到 WAV 的成功路径；仅在所有解码尝试失败后判为输入错误。

## Migration Plan

1. 实现并通过前端、后端单元测试及 OpenSpec 严格校验。
2. 在本机构建 sidecar 和桌面应用，替换前备份现有 `/Applications/Voicebox.app`，启动后检查健康接口。
3. 手工验证：克隆声音不能提交 CustomVoice；选择 Vivian 后提交 CustomVoice；正常麦克风听写；构造损坏录音并检查 4xx 与清理；模拟转写异常并检查诊断编号。
4. 若启动或冒烟验证失败，退出新应用并恢复构建前备份；原有 SQLite 数据和音频目录不迁移、不删除。
